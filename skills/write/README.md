# 通用技术文档纯文字撰写技能 (`write`)

本技能专注于所有文档类工作（系统架构方案、工程技术规范、算法设计说明、接口契约文档、技术白皮书、工程复盘总结等）的**纯文字口吻、叙事手法、逻辑推导与工程注意事项**。

普适于 Markdown (`.md`)、在线 Wiki、技术文档库、方案汇报及各类交付文本，完全摆脱排版格式的约束，聚焦于高质量的技术内容输出。

## 技能定位

- **纯文字工程写作准则**：聚焦于文字口吻、叙事手法与注意事项，不掺杂特定文件格式排版。
- **客观沉稳的工程师口吻**：开门见山、事实先行，严禁复述需求，杜绝一切 AI 套话与浮夸口号。
- **基于约束与权衡的叙事手法**：从实际物理与系统矛盾出发，层层递进推导方案因果链路，虚实分明地展现工程边界。
- **严密自洽的数学表达**：公式出现后正下方即时交代变量定义与物理工程含义，保持符号全局唯一，结合真实量纲可推演复算。
- **全面的系统兜底意识**：不仅阐述理想链路，更深入剖析边界约束、异常防御与安全降级策略。
- **全维度脱敏解耦**：采用通用工程学与控制理论抽象表达，不涉及任何私有商业实体与特定机型。
