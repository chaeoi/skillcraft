# 学术论文与工程技术文献翻译技能 (Academic Paper Translation Craft)

本技能专注于**高严谨度学术论文、外文专利与工程技术规范的端到端翻译、图表原貌复原、公式数学建模与交付级 Word (`.docx`) 排版**。

论文翻译绝非简单的文本语言转换，而是包含“原始文献只读归档 $\to$ 图像矢量边界精准提取 $\to$ 双语术语严密对照 $\to$ LaTeX/OMML 矢量公式转译 $\to$ 自适应长宽比插图排版 $\to$ 自动化编译与逐页目检”的完整工程化流水线。彻底杜绝机械翻译腔、AI 臆造解释、图表内容截断与版面突兀失衡。

---

## 一、 核心铁律与资产分层规范

所有论文翻译任务，必须严格实行“原件、中间稿、交付件”的三层单射平铺目录架构，统一以论文原英文题名命名，杜绝散乱目录与层级嵌套：

```text
papers/originals/<Paper Title>.pdf            # 1. 原始论文 PDF：只读物理归档，绝对严禁覆盖或改写
papers/intermediate/<Paper Title>.md          # 2. Markdown 中间工作稿：翻译文字、结构与公式维护中心
papers/intermediate/images/<Paper Title>/     #    插图提取目录：全套原分辨率提取的插图
papers/translations/<Paper Title>.docx        # 3. Word 最终交付件：集中平铺，供一键下载与正式交付
```

### 编写与维护铁律
1. **Markdown 是唯一维护入口，Word 是编译输出件**：
   - 任何改动均在 Markdown 中间稿或提取图片中进行，随后通过编译脚本生成 Word，**严禁手工修改已生成的 `.docx`**。
2. **原始 PDF 只读铁律**：
   - 原件是核查图表、公式、数据的唯一客观基准，坚决保持只读归档。
3. **相对路径唯一性**：
   - 图片引用必须统一为相对于 Markdown 的相对路径：`images/<Paper Title>/figN.png`，严禁绝对路径与外链图床。

## 二、 翻译口吻与学术叙事准则

1. **客观求真，绝不混入推测性臆造**：
   - 忠实转译原作者表达与技术事实；对不明确或推导省略处，如实反映原文表述，**严禁擅自加入 AI 的推测性解释、杜撰背景或无依据的发挥**。
2. **沉稳克制的学术中文，杜绝机械机翻腔**：
   - 严禁生硬直译与被动语态堆砌（如“被用于”、“被展示”、“它是显而易见的”）；
   - 使用规范的现代汉语工程用语，长句合理切分，语义逻辑顺畅，符合中文专业论文的阅读习惯。
3. **专业术语严密统一**：
   - 建立论文全局术语基准，同一概念全文符号与译名绝对统一（例如：Finite Element Analysis $\to$ 有限元分析/FEA，Degree of Freedom $\to$ 自由度/DoF，Signal-to-Noise Ratio $\to$ 信噪比/SNR，Pulse Width Modulation $\to$ 脉宽调制/PWM）；
   - 关键专有名词、特有缩写首次出现时保留英文标注，如“有限元分析（Finite Element Analysis, FEA）”。
4. **层级与结构 1:1 映射**：
   - 严格保留原文标题梯队（摘要、引言、机构与方法、实验与结果、讨论、结论与参考文献）；
   - 保留原文公式编号、表格编号与图题编号，不增删颠倒。

## 三、 图表提取与完整性核心红线（绝不允许截断）

图片截断与错配是论文翻译交付的最高频严重缺陷。必须遵循以下提取铁律：

1. **严禁依赖自动边缘裁图或 OCR 裁切**：
   - 绝不要用整页非白像素边界或文本检测框自动裁图！此类算法会无情切断图内文字标注、微小指示箭头、坐标轴刻度、colorbar 数值与局部轮廓；
   - 每张图必须对照原 PDF 页面视觉边界人工或高精度定框提取，**宁可保留 5~10 pt 白边，也绝不能贴边切损任何图内信息**。
2. **多切片图垂直拼接复原**：
   - 现代学术期刊（如 IEEE、Elsevier、Nature）中常将一个大图拆为 2~3 个横向切片流式排版（例如上半部分为曲线束，下半部分为坐标轴刻度）。必须核实并使用图像脚本沿垂直方向高保真拼接，恢复完整全图，严禁只截半截。
3. **多子图复合完整性**：
   - 原文图题下若包含 `(a)`, `(b)`, `(c)` 多个子图，提取时必须完整囊括所有子图与对应的字母标签，不得遗漏任何一个分支实验或对比序列。
4. **图号与图题严密单射对应**：
   - 严禁一张图重复引用到不同图题下；
   - 提取完成后，必须核对每一张图片的 MD5、视觉特征与 Markdown 引用的图题，确保图文一一对应。

## 四、 LaTeX 数学公式与语法转译规程

公式必须使用标准 Markdown LaTeX 编写，以确保 Pandoc 能够精准生成 Word 原生 Office Math (OMML) 矢量公式：

1. **块级公式语法**：
   - 独立公式使用 `$$...$$` 包裹；
   - 公式编号使用 `\qquad (1)`，**严禁使用 `\tag{1}`**（Pandoc 对 `\tag{}` 的支持存在缺陷，会导致公式编号丢失或引发编译解析失败）。
2. **行内公式语法**：
   - 行内变量与符号使用 `$x$`，排查并杜绝漏配 `$`，防止奇数个 `$` 导致后半段正文大面积排版坍塌。
3. **转义字符防损陷阱**：
   - `\text{...}` 中的中文与英文必须转义干净，避免 Python 字符串处理时将 `\t` 解释为制表符；
   - `\left( ... \right)` 定界符必须严格成对，防止因字符转义遗漏导致 `\r` 变为回车换行符。
4. **表格内公式的竖线冲突**：
   - 在 Markdown 表格内书写公式时，绝对值符号必须使用 `\lvert x\rvert`，**严禁在表格内直接写未转义的 `|`**（否则会直接撕裂 Markdown 表格列结构）。

## 五、 自适应插图尺寸策略与 Word 排版系统

插图在 Word 页面中必须与正文和谐共存，严禁一刀切统一拉伸，消除“巨图顶爆全页”与“字图断裂”：

### 1. 动态自适应尺寸准则 (Aspect Ratio Adaptive)
- **版心受限**：A4 纸标准版心宽 14.66 cm（约 5.77 英寸），单张图片最大宽度不得越界。
- **纵向竖图 / 长比例图（$w/h < 0.9$）**：
  - **最大高度严格限制在 3.60 英寸以内**（约 9.1 cm），宽度自适应于 2.2 ~ 3.0 英寸。严禁让竖图达到 5 英寸高度独占大半页，破坏版面流式节奏。
- **近方形图（$0.9 \le w/h < 1.3$）**：
  - 最大宽度限制为 4.25 英寸，最大高度限制为 3.40 英寸，保持方形图紧凑居中。
- **常规横向图（$1.3 \le w/h < 2.2$）**：
  - 最大宽度自适应至 4.90 英寸，最大高度限制为 3.20 英寸，兼顾细节可读性与纵向空间节约。
- **全景 / 多步态条幅宽图（$w/h \ge 2.2$）**：
  - 最大宽度展开至 5.15 英寸（版心适度留白），最大高度控制在 2.30 英寸以内。

### 2. 图题与表格排版规程
- **插图本体**：独立成段，水平居中对齐。
- **图题**：位于插图正下方，五号黑体（SimHei / 9.5 pt），居中对齐，格式为 `图 1 原文图题中文翻译`。
- **表格**：默认强制采用**学术三线表**（顶底 1.5 磅粗线、表头底 0.75 磅细线、无坚线、纯白背景）；表题位于表格正上方居中，五号黑体。

## 六、 自动化流水线与交付质检清单 (Delivery Checklist)

完成 Markdown 翻译与插图提取后，依次执行三步标准流水线：

```bash
python3 tools/repair_markdown.py     # 1. 自动修复转义残损、公式括号与异常控制符
python3 tools/compile_all_docx.py    # 2. 调用 Pandoc 并执行 Word 自适应尺寸与版式后处理
python3 tools/validate_repository.py # 3. 静态语法、公式 OMML、图片引用与页面标头校验
```

### 交付前目检查验清单（不可替代的最终防线）
- [ ] **原件只读**：`papers/originals/` 原始 PDF 毫发无损，无覆盖修改。
- [ ] **插图无截断**：逐图比对原 PDF，坐标轴标题、刻度值、子图编号 `(a)/(b)`、指示箭头无一丝一毫切断。
- [ ] **图号无重配**：MD5 校验无无故重复图片，每个图题对应唯一的正确插图。
- [ ] **公式可交互**：Word 打开后公式为原生矢量 Office Math (OMML)，无虚线方框，无未渲染的原始 LaTeX 源码字符串残留。
- [ ] **表格无畸变**：单元格无竖线穿插，表头重复跨页，表格列对齐工整，无跨页文字撕裂。
- [ ] **页面流式目检**：使用 LibreOffice 导出 PDF 逐页审查，无 5 英寸孤立巨图，无一页仅剩两行字的空白断层，图文呼吸感良好。
