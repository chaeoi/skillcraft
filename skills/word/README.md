# 通用技术文档与工程规范撰写技能 (`word`)

本技能确立了一套普适于**所有文档类工作**（系统架构方案、工程技术规范、算法设计文档、接口契约说明、技术白皮书、工程复盘等）的高严谨度文字叙述手法与质量准则。

无论文档载体是 Word (`.docx`)、Markdown (`.md`)、PDF、在线 Wiki 还是代码库内的设计说明，均通用遵循本技能的行文手法与核心注意事项。

## 技能定位

- **普适文档方法论**：文字叙述手法、因果逻辑、结构闭环与去 AI 感准则覆盖所有技术文档工作，超越单一文件格式。
- **事实驱动自洽**：以实际工程代码与物理实现为根本事实来源，严禁虚构未落地的设想，严格划分三层技术边界。
- **六要素过程闭环**：每个核心技术步骤/算法模块完整落实“输入 $\to$ 处理 $\to$ 公式 $\to$ 判定 $\to$ 输出 $\to$ 异常分支”六要素模型。
- **数学极其严密**：每一个公式下方立即逐一解释全部参数符号与工程意义，保持全文符号唯一性。
- **纯粹工程表达**：开门见山、事实先行，全面杜绝 AI 感、机械八股与需求复述。
- **全维度脱敏解耦**：所有论述、模型与案例均采用通用工程抽象，不涉及具体私有商业项目。
- **原生矢量排版拓展**：当涉及 Word/DOCX 交付时，基于 OMML 原生矢量公式技术，根除公式虚线方框、字符回退与行距错乱。
