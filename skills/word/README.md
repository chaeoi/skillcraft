# Word 专业排版与工程格式规范技能 (`word`)

本技能专注于 **Word (`.docx`) 及正式工程技术报告、设计规范的排版体系与格式规范**。

## 技能定位

- **全文档默认排版基准**：所有 Word (`.docx`) 及正式工程文档产出，**若无特殊要求，均默认且强制采用本套标准工程报告排版规范**，无需每次反复确认。
- **页面与版心设置**：Word 默认 A4 纸张与常规边距，上/下 $2.54\text{ cm}$，左/右 $3.17\text{ cm}$（公文标准装订版心），净版心宽度 $14.66\text{ cm}$，全篇页面尺寸一致。
- **标题层级梯队**：全黑体（Times New Roman 西文），大标题三号居中、一级三号、二级小三号、三级四号，段前段后各 $0.5\text{ 行}$，单倍行距，顶格无缩进，编号无双重继承。
- **正文段落系统**：宋体小四号常规体，Times New Roman 西文，两端对齐，首行严格缩进 $2\text{ 字符}$，段前段后 $0\text{ 磅}$，单倍行距；中西文混排启用自动间距与长标识符软换行保护，杜绝大段字距拉伸；自然流式排版无空白页。
- **列表项规范**：宋体小四号，全角括号序号 `（1）`、`（2）`，首行缩进 $2\text{ 字符}$。
- **图表与题注**：图题位于插图正下方居中（黑体五号）；表题位于表格正上方居中（黑体五号）；表格默认采用**学术三线表**（顶底 $1.5\text{ 磅}$、表头底线 $0.75\text{ 磅}$、无竖线、白底无斑马纹），表头加粗居中，重要表格保持单页完整不跨页撕裂。
- **代码清单框**：纯白背景、$0.5\text{ 磅}$ 浅灰细实线边框、Consolas $9\text{ pt}$ 等宽字体，不残留网页深灰底色。
- **独立公式规范**：公式居中独立排版，编号靠右；参数说明段紧随其后首行缩进 $2\text{ 字符}$；一律采用 Word 原生公式而非字符拼凑。
- **原生矢量排版 (OMML)**：在输出 Word/DOCX 时，基于 Office Math 原生矢量公式彻底根除方框乱码与行高突变。
- **分节与页码体系**：目录节用罗马数字页脚与点导线右对齐，正文节从 1 重新起编并带统一页眉，目录页码与正文精确对应。
