# 代码编写与架构工程规范 (`code`)

一个面向 Codex 编码协作的实用主义开发与架构规范 Skill。基于多类工程工具、轻量服务与模块实践的高标准工程习惯沉淀而成，指导 AI 代理在进行架构设计、编码实现、功能重构和测试交付时保持一致的工程品味。

## 技能定位

- **实用主义 Vibe Coding**：拒绝为未来不存在的场景做过度设计，最短运行链路，快速验证闭环。
- **纯静态与轻量优先**：能用原生前端与静态部署绝不引入厚重框架与冗余依赖。
- **前后端契约严谨**：接口定义清晰、路径与错误状态码规范、数据流透明。
- **生产级可交付**：关注可维护性、测试覆盖率、资源占用与安全边界。
- **坚决杜绝 AI 感**：代码注释求真求实，严禁机械复述需求或解释显而易见的代码；文案与交互保持专业克制的人类工程师风格。

## 触发与使用

### 显式触发

在与 Codex 交互时使用 `$code` 触发：

```text
使用 $code 设计并实现一个静态工具的前端界面，要求纯原生 JS 驱动、最小链路。
```

```text
使用 $code 审查当前项目架构，检查前后端契约、配置收敛性与测试用例完备性。
```

### 隐式规则生效

本技能通过 `agents/openai.yaml` 配置了 `allow_implicit_invocation: true`，在涉及代码设计、重构、开发与交付时自动作为底层协作原则生效。
