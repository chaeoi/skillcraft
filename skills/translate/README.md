# 学术论文与工程文献翻译技能 (Translate)

面向 Codex 与技术团队的高严谨度学术论文、外文专利与工程技术文献端到端翻译与标准排版技能。

---

## 技能定位与核心价值

本技能针对学术论文翻译中的核心痛点（原件保护、机翻套话、图表截断、公式报错、版面过大失衡）构建了完整的标准作业程序（SOP）：

1. **三层单射资产架构**：
   - `papers/originals/`（原始 PDF 只读归档，防篡改）
   - `papers/intermediate/`（Markdown 工作稿 + 提取图片中心）
   - `papers/translations/`（Word 交付件集中平铺）
2. **高保真图表无损提取**：
   - 彻底摒弃自动非白裁剪，采用多切片高保真拼接与保护性边界定框，确保坐标轴、刻度线、箭头与子图完整无损。
3. **原生矢量数学公式规程**：
   - 块级公式 `\qquad (1)` 编号标准（杜绝 `\tag{}`），严密转义保护，原生 Office Math (OMML) 交互式渲染。
4. **长宽比自适应控高控宽与结构分区对齐**：
   - 突破传统统一拉伸限制，根据长宽比动态调节纵向竖图与全景横图尺寸，杜绝“一张图占大半页”的版面压迫感；
   - 严密区分文首元数据（严格左对齐 `left`）与学术正文主体（两端对齐 `both`），杜绝作者机构拉伸空隙与正文参差毛边。
5. **ECMA-376 与 OpenXML 健壮后处理**：
   - 保持 `styles.xml` 原生纯净基线，仅在 `document.xml` 中执行标准属性注入；
   - 对段落属性 `<w:pPr>` 子元素执行 ECMA-376 严格序列排序，保留原生命名空间前缀，保障 Word 原生双击解析与样式表加载完全合规。
6. **双重闭环质检与强制目检**：
   - 脚本静态校验结合 Headless PDF 逐页视觉目检，无论初次编译还是后续微调，均闭环核验，确保交付品质。

## 触发与使用

### 提示词触发

在会话中直接输入：

```text
使用 $translate 翻译 papers/originals/ 下的新增论文，生成 Markdown 工作稿与 Word 交付件
```

或者自然语言触发：
- “请帮我翻译这篇论文，提取其中的高清插图并导出为符合标准排版的 Word 文档。”
- “检查翻译件中图片显示不全和排版过大的问题并修复。”

## 协同工作关系

- **`word` 技能**：负责最终 Word 的底层页边距（默认 A4、常规边距）、黑体标题梯队、宋体小四号正文、学术三线表与页眉页脚体系。
- **`write` 技能**：负责中文正文文本的工程师口吻、逻辑闭环与去 AI 感。
- **`translate` 技能**：统领文献双语转换、原始 PDF 对照提取、多切片拼合、自适应插图排版与自动化编译验证。
