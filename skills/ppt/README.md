# PPT 汇报技能

一个面向中文技术汇报、研究进展、项目复盘和管理简报的 Codex Skill。它将内容组织成克制、成熟、信息充实的蓝色系演示文稿，并默认执行匿名化与交付前隐私检查。

这个 Skill 负责演示文稿的叙事、写作、视觉风格、信息密度和验收标准；实际读取、生成或修改 `.pptx` / `.potx` 文件时，需要与 Codex 内置的 `pptx` Skill 配合使用。

## 主要能力

- 先提炼汇报结论和听众需要理解的问题，再规划每页的任务与重点。
- 压缩背景和流程说明，把主要篇幅留给进展、证据、问题与后续行动。
- 使用适合技术和学术汇报的克制蓝色视觉系统，强调对齐、层级与可读性。
- 用明确的 `已完成`、`进行中`、`待提高`、`未完成` 描述真实进度。
- 默认匿名化组织、团队、项目和个人信息，并检查正文、媒体、备注、链接及元数据。
- 在交付前检查叙事、版式、Windows 兼容性、PPTX 包结构和 PDF 渲染结果。

## 安装

使用 Skillcraft 根目录安装脚本：

```bash
# 符号链接模式（推荐）
./scripts/install.sh --link ppt

# 复制模式
./scripts/install.sh ppt
```

也可以手动安装至 Codex 的 Skills 目录：

```bash
ln -sfn "$(pwd)" ~/.codex/skills/ppt
```

## 使用

该 Skill 默认关闭隐式调用，需要在提示词中明确写出 `$ppt`。例如：

```text
使用 $ppt 将这份材料整理成简洁、成熟、内容充实且默认匿名化的中文汇报 PPT。
```

也可以指定更具体的任务：

```text
使用 $ppt 修改 progress.pptx。保留现有模板，把流程压缩为一页，重点呈现当前进展、两个主要问题和下一阶段计划；除项目名称外，其余身份信息全部匿名化。
```

当任务涉及 `.pptx` 或 `.potx` 时，Codex 会同时使用 `pptx` Skill 完成底层文件处理、渲染和验证。

## 默认设计规范

| 项目 | 默认值 |
|---|---|
| 画布 | 16:9 宽屏 |
| 主色 | `#155F96` |
| 深色强调 | `#1D4563` |
| 标题文字 | `#18211F` |
| 中文字体 | Microsoft YaHei / 微软雅黑 |
| 内容页标题 | 28-32 pt |
| 正文字号 | 11-15 pt |
| 风格 | 白底、克制蓝、轻边框、少阴影、无装饰性渐变 |

完整参数和可复用版式见 [`references/styleguide.md`](references/styleguide.md)。
