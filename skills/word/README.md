# Word 深度技术方案与规范撰写技能 (`word`)

本技能用于严谨工程技术规范、系统架构方案与高规格技术报告的深度规划、撰写、重构与排版交付。

## 技能定位

- **严密自洽**：以实际工程代码与物理实现为根本事实来源，严禁虚构未落地的设想。
- **过程闭环**：每个技术步骤完整落实“输入 $\to$ 处理 $\to$ 公式 $\to$ 判定 $\to$ 输出 $\to$ 异常分支”六要素模型。
- **数学严密**：每一个公式下方立即逐一解释全部参数符号与工程意义，保持全文符号唯一性。
- **纯粹表达**：全面杜绝 AI 感、机械八股与需求复述。
- **原生排版**：基于 OMML 原生矢量公式技术，根除公式虚线方框、字符回退与行距错乱。
- **彻底脱敏**：所有论述、模型与案例均采用通用工程抽象，不涉及具体私有商业项目。
