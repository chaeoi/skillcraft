# 代码编写与架构工程规范 (Code Craft & Architecture)

遵循实用主义开发哲学与工程习惯。本技能适用于代码编写、系统设计、重构、测试验证及文档交付。

## 核心设计与执行准则

1. **工程审美与设计品味**：追求极简、优雅、高可读性与高健壮性的工程实现。
2. **前后端解耦与契约清晰**：保持 API 接口设计紧凑、语义明确、字段唯一。
3. **最短运行链路**：拒绝过度抽象与过度设计，优先采用直接、高效的实现方式。
4. **轻量与纯静态优先**：对于 Web 工具类项目，优先选用轻量纯静态（HTML/JS/CSS）方案，降低运行依赖。
5. **规范分层与模块拆分**：按清晰职责切分工程目录，保持核心逻辑自洽且易于测试。
6. **零 AI 味与无废话注释**：代码注释求真求实，仅在必要处解释复杂算法或设计权衡，坚决杜绝模板化套话、机械复述需求或解释显而易见的代码。
